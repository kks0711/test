⚙️ 설정

❓ 게임 방법

🖱️ 컴퓨터

  • 화면 클릭 → 마우스로 둘러보기 시작 (ESC로 해제)
  • W A S D 또는 방향키 → 걷기
  • 스페이스 → 점프 / 물에서 헤엄치기
  • 왼쪽 클릭 → 블럭 부수기 ⛏️
  • 오른쪽 클릭 → 블럭 놓기 🧱
  • 1~9 숫자키 / 휠 → 핫바 블럭 고르기
  • F → 날기 (🕊️ 날개를 산 다음에!)
  • E 가방 · Q 퀴즈 · B 상점 · M 미션

📱 태블릿/폰

  • 왼쪽 스틱 → 걷기
  • 오른쪽 화면 드래그 → 둘러보기
  • ⛏️ 버튼 → 조준한 블럭 부수기
  • 🧱 버튼 → 조준한 곳에 블럭 놓기
  • ⬆️ 버튼 → 점프

💰 코인 모으기

  • 📖 퀴즈 정답 (⭐ 어려울수록 더 많이!)
  • 🏆 미션 완수 보상
  • 🎁 매일 접속 선물
💡 흙·돌·나무는 직접 캐면 공짜! 유리·금·다이아·무지개 같은 특별한 블럭은 상점에서 사요.
