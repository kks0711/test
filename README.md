# ⛪ 성경 블럭 왕국 (Bible Block Kingdom 3D)

어린이를 위한 **성경 퀴즈 × 마인크래프트 스타일 3D 건축 게임**입니다.
넓은 3D 세상을 탐험하며 땅을 파고, 성경 퀴즈로 코인을 모아 특별한 블럭과 능력을 사서 나만의 세상을 만들어요!

## 🎮 실행 방법

설치가 필요 없습니다. `index.html`을 크롬/엣지 브라우저로 열면 바로 실행됩니다.

```bash
# 또는 로컬 서버로 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 🌍 진짜 마인크래프트처럼

- **1인칭 3D 월드** — 순수 WebGL로 직접 만든 복셀 엔진 (외부 라이브러리 0개)
- **256 × 256 × 64 절차 생성 지형** — 언덕, 산, 숲, 사막, 설원, 얼음 호수, 강이 매번 다르게 생성
- 나무 🌳, 꽃 🌸, 선인장 🌵, 그리고 돌 속에 숨은 **금·다이아 광석** ⛏️
- **낮과 밤**이 바뀌고 노을이 지는 하늘, 거리 안개, 물속 효과
- 걷기·점프·수영·**날기**(날개 구매 시), 중력과 충돌 물리
- 블럭 24종: 잔디, 흙, 돌, 모래, 원목, 나뭇잎, 물, 눈, 얼음, 유리, 벽돌, 판자, 조약돌, 금, 다이아, 무지개, 반짝돌(밤에 빛남!), 양털, 꽃 등

## 🛠️ 기술

- 순수 HTML/CSS/JavaScript — 외부 라이브러리, 이미지 파일 없음
- WebGL 청크 렌더링(16×64×16), 시드 기반 노이즈 지형 생성, 복셀 레이캐스팅(DDA), AABB 충돌 물리
- 텍스처는 캔버스로 절차 생성, 효과음은 Web Audio로 합성

```
js/noise.js      시드 노이즈 (지형)
js/blocks.js     블럭 정의 + 텍스처 아틀라스
js/quiz-data.js  퀴즈 170+ 문제, 말씀 카드
js/world.js      256x256 지형 생성
js/mesher.js     청크 → 삼각형 메시
js/renderer.js   WebGL 렌더러 (낮밤/안개/하이라이트)
js/player.js     1인칭 물리 + 레이캐스트
js/ui.js         퀴즈/상점/가방/미션/카드 UI
js/game.js       메인 루프, 입력, 저장
```
