# ⛪ 성경 블럭 왕국 (Bible Block Kingdom)

어린이를 위한 **성경 퀴즈 × 블럭 쌓기** 게임입니다.
성경 퀴즈를 맞히면 코인을 받고, 그 코인으로 블럭을 사서 마인크래프트처럼 나만의 세상을 만들어요!

## 🎮 실행 방법

별도의 설치가 필요 없습니다. `index.html` 파일을 브라우저(크롬, 엣지 등)에서 열면 바로 실행됩니다.

```bash
# 또는 간단한 로컬 서버로 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 📖 게임 방법

1. **퀴즈 풀고 코인 받기** 버튼을 눌러 성경 퀴즈를 풀어요 (총 40문제, 4지선다).
2. 정답을 맞히면 🪙 **코인 10개**를 받아요. 3문제 연속 정답이면 **보너스 +5**!
   틀려도 참가상으로 코인 1개를 받고, 정답과 관련 성경 구절을 알려줘요.
3. 화면 아래 상점에서 코인으로 **블럭을 구매**해요 (한 번에 5개씩).
4. 블럭 카드를 선택하고 **땅을 클릭**하면 블럭이 쌓여요 (최대 7층).
5. ⛏️ **부수기** 모드(또는 마우스 우클릭)로 블럭을 부수면 가방으로 돌아와요.

## 🧱 블럭 종류

잔디 · 흙 · 모래 · 돌 · 나무 · 나뭇잎 · 물 · 눈 · 유리 · 벽돌 · 금 · 다이아 · 무지개 (총 13종)

## ✨ 특징

- **외부 라이브러리 없음** — 순수 HTML/CSS/JavaScript 한 파일
- **아이소메트릭 3D 스타일** 블럭 렌더링 (Canvas)
- **자동 저장** — 쌓은 블럭, 코인, 가방이 브라우저(localStorage)에 저장돼요
- **효과음** — Web Audio로 만든 정답/오답/블럭 소리
- 어린이 눈높이의 큰 버튼과 쉬운 한국어 UI, 모바일 터치 지원
