SEE-IT 오늘 운영을 돌려라.

절차:
1. Notion MCP에서 SEE-IT 운영 허브, 회의록 통합, Action Item, 운영 리듬, 재정·위험 관련 자료를 조회하라.
2. seeit-ops-lead를 호출하라.
3. 회의록에서 실행 전환이 필요하면 seeit-meeting-action을 호출하라.
4. 최종 제출 전 seeit-risk-auditor를 호출하라.
5. 대표 브리핑으로 종합하라.

최종 출력:
- 대표가 오늘 볼 것
- 윈터가 조율할 것
- 한나가 실행할 것
- 이번 주 병목
- 위험 신호
- 새 Action Item 후보
- 대표 승인 필요
