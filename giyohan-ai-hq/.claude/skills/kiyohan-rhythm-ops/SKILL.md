# 반복운영 점검 스킬

## 목적

반복되는 운영 누락을 막고, 지금 빠진 것과 기한이 임박한 것만 잡는다.

## 기요한 능력 배분

- 조직 운영 리듬 설계
- 반복 업무를 시스템으로 고정하는 감각
- 대표 실무 회귀 방지
- 담당자·기한·완료증거 중심 운영
- 주간/월간 체크포인트 설정

## 점검 시점

- 금요일: 주일 운영판 1차 확인
- 토요일: 예배 준비 최종 확인
- 주일 후: 목양 반응·회계 지출 정리
- 월말: 회계 원자료·행사 자료 정리
- 회의 후: Action Item 반영 확인
