# 실행 전환 스킬

## 목적

말과 논의를 실제 실행 단위로 바꾼다.

## 구분 기준

1. 결정사항: 누가 무엇을 하기로 확정한 것
2. 보류사항: 아직 판단하지 않기로 한 것
3. 위임사항: 특정 사람에게 맡긴 것
4. 질문사항: 추가 확인 없이는 실행할 수 없는 것
5. Action Item: 담당, 기한, 다음 행동, 완료증거가 있는 실행 단위

## Action Item 생성 기준

- 제목
- 담당
- 기한
- 다음 행동
- 완료증거
- 근거
- 대표 판단 필요 여부
