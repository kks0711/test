# 원자료 기반 판단 스킬

## 목적

노션과 문서 원자료를 읽고, 사실·해석·추정·확인 필요를 분리한다.

## 원칙

1. 원자료에 있는 것만 확정한다.
2. 원자료에 없는 것은 `근거 없음`으로 표시한다.
3. 애매한 것은 `확인 필요`로 표시한다.
4. 이름, 날짜, 장소, 인원, 금액, 담당자는 절대 추정하지 않는다.
5. 여러 자료가 충돌하면 `자료 충돌`로 표시하고 대표 판단으로 올린다.
